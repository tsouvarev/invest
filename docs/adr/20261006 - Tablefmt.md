# Форматирование таблиц

## Проблема

Есть несколько команд скрипта, которые выводят таблицы:

- актуальные данные по бумагам
- сравнение снапшотов при актуализации
- поиск бумаг
- поиск и список дубликатов
- просмотр черного списка
- список изменений рейтинга

Все они могут использоваться в рамках консоли,
но сравнение снапшотов еще шлется в телеграм, который использует HTML-формат.

## Варианты решения

- сделать везде одинаковый вывод
  (проблематично, потому что в телеграме сообщение более узкое,
  чем экран консоли, из-за чего не вся информация умещается)
- добавить флаги в хэлперы с форматированием
  (минус в том, что придется этот флаг прокидывать через все вызовы, не по ООП)
- создать классы форматтеров, которые будут вызываться одинаково,
  а отдавать представление каждый по-своему
  (минус в том, что придется писать классы и интерфейсы;
  зато сразу все разведено)

## Реализация

В итоге пока что остановился на флагах,
пока не устаканится форматирование для телеграма.
